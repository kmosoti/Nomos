# Nomos 0.2.0-alpha.1

First pre-release of the `0.2` line, extending the masterless Debian Cell with a headless IPv6 Loom coordinator, fleet adapters, a pure resource governor, and reusable NixOS modules. It ships two Debian packages (`nomos-cell` and `nomos-loom`) built once from the tagged commit. It is an alpha. Use it on hosts you can rebuild.

## Install

Both packages target Debian 12 and 13 on amd64 with systemd. Download `nomos-cell_0.2.0-alpha.1_amd64.deb`, `nomos-loom_0.2.0-alpha.1_amd64.deb`, `SHA256SUMS`, and `RELEASE-EVIDENCE.json` from this release, verify the digests and provenance attestations, and install the role each host runs:

```sh
sha256sum --check --ignore-missing SHA256SUMS
gh attestation verify nomos-cell_0.2.0-alpha.1_amd64.deb --repo kmosoti/Nomos
gh attestation verify nomos-loom_0.2.0-alpha.1_amd64.deb --repo kmosoti/Nomos
sudo apt-get install ./nomos-cell_0.2.0-alpha.1_amd64.deb
sudo apt-get install ./nomos-loom_0.2.0-alpha.1_amd64.deb
```

`nomos-cell` installs `/usr/bin/nomos-cell` with its systemd oneshot service and timer and declares `Depends: systemd, dbus, passwd, apt`. `nomos-loom` installs `/usr/bin/nomos-loom` with `nomos-loom.service`, declares `Depends: libc6, systemd`, and listens on `[::1]:7440` (HTTP) and `[::1]:7443` (QUIC) with state under `/var/lib/nomos-loom/leases.sqlite`.

## What Changed

- **Headless Loom coordinator.** `nomos-loom` runs pure-IPv6 HTTP, Server-Sent Events (SSE), and pinned QUIC Remote Procedure Call (RPC) listeners backed by an SQLite Write-Ahead Log (WAL) credential lease broker. When `--web-assets-dir` is omitted, fallback routes return a compact JSON status object and `/health` reports `"headless": true`.
- **Two Debian packages in one release.** `cargo xtask package` builds both `nomos-cell` (static `musl`) and `nomos-loom` (`gnu`) into one directory with a sorted `SHA256SUMS`. The release job checks both digests against the build job's outputs and attaches build provenance attestations to both `.deb` files.
- **Age and vTPM 2.0 cipher adapter.** `nomos-cipher` and `nomos-cipher-age-vtpm` add data-driven `SecretPolicy` and `NodeTarget` synchronization, `systemd-creds` Virtual Trusted Platform Module (vTPM) 2.0 verification, and metadata-only `SecretsPosture` reporting without exposing plaintext secrets.
- **WireGuard mesh and pinned QUIC transport.** `nomos-mesh-wireguard` and `nomos-protocol-quic` add a pure-IPv6 zero-allocation tunnel data plane and Ed25519 fingerprint-pinned QUIC RPC and datagram transport.
- **Google Cloud adapter and pure resource governor.** `nomos-cloud` and `nomos-cloud-gcp` add a pure-IPv6 Google Cloud Platform (GCP) Compute Engine and Spot Batch adapter tested against a mock IPv6 HTTP server, paired with a `#![no_std]` Pressure Stall Information (PSI) and control group governor (`ServiceGovernor`) in `nomos-core`.
- **Reusable NixOS modules.** `flake.nix` exports parameterized `nixosModules` (`default`, `base-ipv6`, `wireguard-wg0`, `secrets`, and `deadman-rollback`) with documentation and unique-local IPv6 addressing defaults. `wireguard-wg0` derives tunnel Maximum Transmission Unit (MTU) as `outerPmtu - 80` and fails evaluation if the result drops below `1200` or if non-IPv6 addresses appear.
- **Dated release rules and Rust 1.100.0 toolchain.** The workspace, CI, and `rust-toolchain.toml` are pinned to Rust 1.100.0 (Edition 2024). Dated patterns in `verification/trust-boundary.toml` hold each commit in a release range only to the rules in force when that commit was written.

## Upgrading From alpha.2

Upgrading `nomos-cell` with `sudo apt-get install ./nomos-cell_0.2.0-alpha.1_amd64.deb` replaces `/usr/bin/nomos-cell` in place while preserving `/etc/nomos` and `/var/lib/nomos` (mode `0700`). Installing `nomos-loom` is additive and optional: a host running only the masterless Cell does not need `nomos-loom`.

## What It Does Not Establish

- **Live Loom-to-Cell fleet convergence.** The Debian 12 and 13 container suites install, converge, upgrade, remove, and purge `nomos-cell` byte for byte and tie that proof into `RELEASE-EVIDENCE.json`. `nomos-loom` is verified by unit and integration tests and its digest is checked in the release workflow, not by a multi-host Debian container suite.
- **Live cloud, hardware vTPM, or WireGuard kernel peers.** The GCP adapter is exercised against a mock IPv6 HTTP server, and the vTPM and mesh suites run in-process without cloud credentials, physical hardware tokens, or live kernel WireGuard interfaces.
- **The repository rules.** Protected `main` and `v*` tags are repository settings that no code here can check.
- **Reproducible builds and apt signatures.** Packages are built once so the validated bytes are the published bytes, not rebuilt to prove determinism, and neither `.deb` carries an apt repository signature. Verify both with `SHA256SUMS` and `gh attestation verify`.
- **Hosts and alpha.1 limits.** Every Debian result comes from a privileged container booting systemd, not a virtual machine or bare metal. Power loss, concurrent external writers, and real-archive scale remain unchecked.

## Know Before You Use It

The Canon runs as root and is not signed, the Cell journal grows without compaction, and removing either package does not undo host changes already enforced. The Phase 1 Cell threat boundaries live in [docs/security-model.md](https://github.com/kmosoti/Nomos/blob/v0.2.0-alpha.1/docs/security-model.md), and [docs/operator-guide.md](https://github.com/kmosoti/Nomos/blob/v0.2.0-alpha.1/docs/operator-guide.md) documents both `nomos-cell` and headless `nomos-loom`.
