# Nomos 0.2.1-alpha.1

Security hardening pre-release of the `0.2` line addressing Daybreak security findings across the Loom coordinator, Quick User Datagram Protocol Internet Connections (QUIC) control plane, Google Cloud Platform (GCP) adapter, Linux substrate, WireGuard mesh, and cipher transport. It is an alpha. Use it on hosts you can rebuild.

## Install

Both packages target Debian 12 and 13 on amd64 with systemd. Download `nomos-cell_0.2.1-alpha.1_amd64.deb`, `nomos-loom_0.2.1-alpha.1_amd64.deb`, `SHA256SUMS`, and `RELEASE-EVIDENCE.json` from this release, verify the digests and provenance attestations, and upgrade or install each host role:

```sh
sha256sum --check --ignore-missing SHA256SUMS
gh attestation verify nomos-cell_0.2.1-alpha.1_amd64.deb --repo kmosoti/Nomos
gh attestation verify nomos-loom_0.2.1-alpha.1_amd64.deb --repo kmosoti/Nomos
sudo apt-get install ./nomos-cell_0.2.1-alpha.1_amd64.deb
sudo apt-get install ./nomos-loom_0.2.1-alpha.1_amd64.deb
```

## What Changed

- **Pinned QUIC role isolation and admission bounds.** `nomos-protocol-quic` extracts the verified peer SubjectPublicKeyInfo (SPKI) SHA-256 fingerprint via `ControlHandler::handle_authenticated` and `ControlHandler::handle_telemetry_authenticated`, caps concurrent handshakes, connections, per-IP and per-peer sessions, and datagram rates, and enforces transport stream and idle limits. `nomos-loom` enforces `PeerRole::Authority` versus `PeerRole::Cell` pins, rejects `SubmitPlan` from Cell or unauthenticated pins, bounds generation leaps and rejects divergent or replayed Plan redeliveries before persistence, and isolates per-pin telemetry from local governor admission.
- **Loom HTTP, static asset, and SQLite Write-Ahead Log (WAL) hardening.** `nomos-loom` refuses plain HTTP binds on non-loopback addresses without `--behind-tls-proxy`, requires bearer authentication on lease inspection, verification, governor, telemetry, and Server-Sent Events (SSE) endpoints while keeping `/health` minimal, prevents child lease delegation on `POST /v1/leases` and `DELETE /v1/leases/{id}`, transactionally prunes expired or revoked SQLite rows with bounded table growth and WAL checkpoints, and rejects symlinks, non-regular files, and canonical-root escapes when serving `--web-assets-dir`.
- **GCP URL, identifier, and idempotency hardening.** `nomos-cloud` and `nomos-cloud-gcp` enforce strict GCP naming and IPv6 Classless Inter-Domain Routing (CIDR) grammars, construct all REST paths and queries through `reqwest::Url` with origin-pinned Long-Running Operation (LRO) `selfLink` checks, disable HTTP redirects on credentialed clients, and include observed resource state and execution epoch in Universally Unique Identifier Version 5 (UUIDv5) `requestId` values so drift repairs are not suppressed.
- **Linux execution deadlines and cross-reboot clock continuity.** `nomos-app`, `nomos-substrate`, `nomos-substrate-linux`, and `nomos-cell` enforce `settle_by` deadlines before every mutation and unit operation, and bind persisted instants across `/proc/sys/kernel/random/boot_id` changes and wall-clock intervals so reboots neither reset cooldowns nor stall expired deadlines.
- **WireGuard destination checks and Secure Shell (SSH) cipher hardening.** `nomos-mesh-wireguard` authorizes inner IPv6 destination prefixes and optional User Datagram Protocol (UDP) port ranges inside its zero-allocation data plane while rejecting port-0, unspecified, and multicast packets. `nomos-cipher-age-vtpm` wraps private key encodings in `Zeroizing<String>`, bounds SSH runtime and pipe output bytes with keepalives, and isolates per-target transport errors during synchronization.
- **Repository ruleset parity.** `.github/rulesets/main.json` matches the live protected branch configuration requiring code-owner review, dismissed stale approvals, resolved review threads, and rebase merges.

## Upgrading From 0.2.0-alpha.1

Install `nomos-cell_0.2.1-alpha.1_amd64.deb` and `nomos-loom_0.2.1-alpha.1_amd64.deb` with `apt-get install` to replace the binaries in place while keeping existing `/etc/nomos` and `/var/lib/nomos` directories. When launching `nomos-loom serve`, assign authority coordinator pins with `--authority-pin` (bare `--allowed-client-pin` entries default to least-privilege `Cell` pins) and bind HTTP to `[::1]` unless running behind a Transport Layer Security (TLS) terminating proxy with `--behind-tls-proxy`.
