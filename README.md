# Nomos

Declarative host-state convergence, distributed execution, and fleet
coordination for Linux. A Moiric project.

> Observe reality, compare it with Canon, derive the smallest valid change,
> apply that change under explicit safety constraints, verify reality again,
> and preserve what happened as immutable history.

**Status:** skeleton. The workspace contains crate boundaries only. There is no implementation yet.
